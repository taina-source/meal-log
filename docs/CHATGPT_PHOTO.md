# 写真 → ChatGPT → Meal Log（第3B-2）

正式なiPhone運用は**JSONのクリップボード受け渡し**です。食事写真をChatGPTアプリへ添付して解析し、回答JSONをコピーして、普段のホーム画面Meal Logで確認・編集・登録します。Meal Logは写真解析やAPI通信をせず、APIキー・追加の従量料金・バックエンドはありません。契約済みChatGPTアプリの利用条件・利用制限は引き続き適用されます。

## 実際の操作

1. 普段のホーム画面Meal Log → ＋ → **「写真からChatGPT取り込み」**を開きます。
2. **「写真解析プロンプトをコピー」**をタップします。コピーできない場合は表示されるプロンプト欄を長押しして、すべて選択・コピーしてください。「プロンプトを表示・手動コピー」からも利用できます。
3. 自分でChatGPTアプリへ切り替え、食事写真を撮影または選択して添付します。Meal Logに写真を添付する操作はありません。
4. プロンプトを貼り付け、必要な補足を末尾に追加して送信します。例：「ご飯200g、肉250g、マヨネーズなし」「自分は右の皿だけ」「写真の半分だけ食べた」。
5. JSON回答全体をコピーします。複数料理はitemsに分かれます。回答のコピー操作、または長押しでテキストをコピーしてください。説明やコード枠が混じった場合はJSONだけに直してもらいます。
6. **普段のホーム画面Meal Log**へ戻り、＋ → 写真からChatGPT取り込み → **「クリップボードから結果を読み込む」**。拒否・非対応の場合は「JSONを貼り付け」欄を長押ししてペースト →「読み込む」。
7. 写真推定の注意、料理名、数量・単位、kcal/PFC、信頼度、推定時のメモを確認します。値を編集し、食事区分・日時を選んで登録します。
8. Homeの合計とHistoryの詳細を確認します。元のChatGPT値とメモはsnapshotとして残ります。

ChatGPT側から始める場合は、あらかじめ下のプロンプトを保存しておき、写真と一緒に送信してから手順5へ進めます。**JSONをコピーした後に「プロンプトをコピー」を押すとクリップボードが上書きされます**。結果ができたら「結果を読み込む」を使ってください。

このiPhone実機ではfragment URLを開くとSafariになり、ホーム画面PWAと履歴／IndexedDBが共有されませんでした。また「Appを開く」でホーム画面PWAのMeal Logを選べませんでした。URLによるPWA直接起動を正式ルートにはしません。アプリの切り替えは手動です。

## inputType・数量・栄養値

- schemaVersionは**1のまま**。ルートに任意の`inputType: "photo"`を追加。`"text"`または未指定はテキスト／旧形式です。未知のinputTypeやnullは入力エラーにします。
- itemのschemaは第3B-1と同じです。写真JSONはテキスト入口でも写真として判定します。逆に写真入口でinputType未指定のJSONを読み込むとテキスト扱いの注意を表示し、写真へ自動変更しません。写真の結果なら写真用プロンプトでJSONを出し直してください。
- 基本は`quantity=1, unit="写真の1皿分"`で、その皿全体の栄養値。半分食べたなら数量1・単位「写真の皿の半分」とし、食べた分の栄養値にします。
- 個数が確かな餃子などは1個の栄養値×個数でも構いません。**5個合計250kcalなら、数量1・250kcalか、数量5・1個50kcal**です。アプリは数量を1回掛けるため、数量5・250kcalと入れると1250kcalになることに注意してください。
- アプリから写真の量を再推定したり、数値を丸め直したりしません。写真推定の目安の丸め（10kcal、PFC1g）はプロンプト側のみ。既存の公式データの精度は維持します。
- null・欠落値は0にせず、確認画面で補完するまで登録不可。負値・非有限値・数量0・21件以上・過大JSONの安全処理も維持します。

## 出典・信頼度・notes・修正

写真の見た目による推定はsourceType=estimateで、確認・履歴に**「ChatGPT写真推定」**と表示します。テキスト推定の表示は従来の「ChatGPT推定」です。

ユーザーが店名・商品名・サイズを明示し、ChatGPTが同一商品の公式情報を実際に確認できた場合だけofficialを許可するプロンプトです。アプリはそれを検証済み公式DBへ昇格させず、従来どおり「ChatGPT経由・公式情報」と表示します。出典URLなし／無効なら注意も表示します。

confidenceはhigh/medium/lowを**「推定信頼度：高／中／低（ChatGPTの申告）」**として表示。「高」でも正確さを保証しません。notesは**「推定時のメモ」**として、量・油・隠れた材料・複数人分の仮定等を表示します。

元の栄養値・数量・メモ・inputTypeはchatgptSnapshotに保存。編集後の値はMealEntry本体へ保存します。chatgptUserModifiedを維持し、今回追加した任意フラグchatgptModifiedBeforeSaveで「登録前にユーザー修正あり」と明示します。保存後の履歴編集を登録前の修正と誤表示しません。過去の第3B-1記録は従来の修正表示を維持します。前日コピーもsnapshotを保持し、コピー先のgroup IDだけを新しくします。

## 「Meal Log 写真解析」ショートカット案

画像をAsk ChatGPTへ自動送信し、結果を自動取得できる前提にはしません。

1. 任意で「入力を要求」を追加。質問：「量・料理名など補足はありますか？」。空欄でも構いません。
2. 「テキスト」に上の写真プロンプト全文を入れ、末尾に入力結果の変数を挿入。
3. 「クリップボードにコピー」へプロンプトのテキストを渡す。
4. 「Appを開く」でChatGPTを選択できるか実機で確認。選べなければこのアクションを省き、自分でChatGPTアプリを開く。
5. ChatGPTで写真を添付し、クリップボードのプロンプトを貼り付けて送信。
6. JSON回答をコピーし、普段のホーム画面Meal Logへ手動で戻る。
7. 写真からChatGPT取り込み → クリップボードから結果を読み込む → 確認・編集・登録。

アクション名はiOSの版・言語で多少異なることがあります。独自のChatGPT URLスキームや画像share extensionには依存しません。

## 限界・プライバシー・オフライン

写真だけでは重量、油、ソース、調味料、隠れた材料を正確に判断できません。写真に見える全量を食べたとは限らず、複数人分や食べ残しも補足してください。写真に写った表示の読めない数字は推測・補完させません。1包装／100gと食べた量の対応も確認します。専用OCR画面はありません。

写真を送る先は、利用者が選んだChatGPTアプリです。Meal Logは写真を受け取らず、画像のアップロード、IndexedDB／localStorageへの画像保存は行いません。base64/blob/画像URL用フィールドも保存しません。parserと保存処理は既知のテキスト・数値項目だけを採用し、余分な画像フィールドを落とします。既知の文字列欄に画像data URLが入った場合は拒否します。写真は栄養JSONに含めないでください。

推定メモと栄養値はユーザー確認後に端末内保存します。回答中のHTMLは実行せず、出典の有効なHTTPSリンクだけを明示操作で開けます。JSON上限は128KiB、itemsは1〜20件を維持します。

ChatGPTの写真解析にはオンライン接続が必要です。取得済みJSONのコピー／手動貼付、確認、編集、登録、Home、History、前日コピーはPWA更新完了後ならオフラインで使えます。再起動で未登録の確認中データは失われるため、元JSONを手元に残してください。
